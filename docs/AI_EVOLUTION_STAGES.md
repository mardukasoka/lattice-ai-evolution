# AI Evolution Research Stages

This project studies capability evolution without assuming that later hypothetical stages will occur.

Working research sequence:

1. contemporary AI / agent systems
2. increasingly general agentic systems
3. AGI hypotheses
4. ASI hypotheses
5. transcendent capability hypotheses
6. cosmic-scale intelligence hypotheses
7. godlike capability hypotheses

Sagent + Fractal provide the bounded recursive-improvement laboratory. RRSI-style evaluation tests whether modifications transfer beyond the tasks that produced them.

Stage labels are research/story categories, not claims that a stage has been achieved.

Every claimed capability transition requires an experiment record, provenance, evaluation evidence and explicit epistemic status.
